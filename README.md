# pywall-pose-game
A simple game that uses your camera to detect motion and challenges you to pass through walls.

## Rough plan
The project will be devided into two main parts.
- Use mediapipe to detect motion using a camera, and get landmarks of the body of the player.
- Build game logic using pygagme and use those values to check for collision with the wall.
